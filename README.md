# Shrabani Neogi — Personal Engineering Portfolio

An interactive, high-performance personal portfolio built for **Shrabani Neogi**, showcasing flagship work in **Agentic AI & RAG**, **Computer Vision Transformers (SegFormer-B0)**, and **Resilient Full-Stack Systems**.

---

## 🌟 Key Features

1. **Cybernetic Visual Aesthetics**:
   - Deep midnight color scheme tailored with rainbow prism illumination accents matching Shrabani's portrait.
   - Interactive particle neural network / constellation canvas background reacting to mouse movement.
   - Frosted glassmorphism panels, glow highlights, and modern typography (`Outfit`, `Inter`, `JetBrains Mono`).

2. **Flagship Projects Showcase with Interactive Simulators**:
   - **ORCA-X (Ocean Reasoning & Collaborative AI)**: Multilingual voice/text query simulator in Bengali, Hindi, and English with Sarvam AI routing and Qdrant RAG telemetry.
   - **Orbivia (AI-Powered Terrain Intelligence)**: Interactive SegFormer-B0 autonomous vehicle decision simulator (GO, SLOW, STOP) with live latency, hazard scores, and segmentation distributions.
   - **MindBloom + Sehat Saarthi**: Dual mental health and 24/7 AI-powered medical triage simulation with emergency GIS dispatch.

3. **Interactive Developer CLI Terminal**:
   - Fully functional cyber shell supporting `help`, `skills`, `projects`, `education`, `metrics`, `hire`, `cat resume`, and math `eval`.

4. **Integrated Curriculum Vitae / Resume Viewer**:
   - Formatted modal with instant print / save-as-PDF capabilities.

5. **Direct Connect & One-Click Actions**:
   - One-click copy email button with animated toast alerts.
   - Direct WhatsApp, LinkedIn, GitHub, and phone links.
   - Validated message transmission form.

## 🚀 Running Locally

The portfolio is built with zero build step dependencies (pure HTML5, CSS3, JavaScript):

```bash
# Navigate to project folder
cd "C:\Users\Shrabani Neogi\.gemini\antigravity-ide\scratch\shrabani-portfolio"

# Serve with Python
python -m http.server 8080
```

Open your browser at `http://localhost:8080`.
